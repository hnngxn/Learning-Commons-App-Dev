# Learning Commons Staff Points — Training Guide

## Purpose
This guide will explain how to enter staff points, review records,
and correct mistakes in the Learning Commons Staff Points System.

## Guide Status
Draft — instructions and screenshots must be verified against the
working application before this guide is used for training.

## Point Rules
- Bonuses increase an employee’s points.
- Infractions decrease an employee’s points.
- Employees working in multiple programs share one total points balance.
- New employees start the semester with 65 points.
- Returning employees start the semester with 70 points.
- Employees become eligible for a raise at 125 points or more.

These rules describe the intended system behavior. Feature availability
must be confirmed in the application.

## Procedures to Document
1. Enter a bonus or infraction.
2. Review and confirm a submission.
3. View staff balances and event history.
4. Correct an incorrect point entry.
5. Enter points for multiple employees.

Each procedure will include verified steps, expected results,
and screenshots from the working application.

## Training Video Outline

Record after the workflows are implemented and verified.

1. Introduce the staff points system.
2. Demonstrate entering a bonus.
3. Demonstrate entering an infraction as a positive amount.
4. Review and submit an entry; show its confirmation.
5. Show the updated balance and event history.
6. Demonstrate correcting an incorrect entry.
7. Demonstrate bulk point entry, if available.

Use sample data and explain the expected result of each action.
