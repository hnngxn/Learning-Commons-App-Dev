# Learning Commons Staff Points — Process Sheet


Status: Draft. Verify these procedures against the completed application
before using this sheet for training.

## Before Entering Points
- Confirm the correct employee.
- Confirm the employee’s program and applicable supervisor.
- Choose the appropriate bonus or infraction event.
- Check the permitted point range and event date.

## Review and Submit
- Review the employee, event, amount, date, and comments.
- Enter infraction amounts as positive numbers; the system should
  apply them as deductions.
- Submit once and wait for the result.
- If the result is unclear, check event history before submitting again.

## Verify the Result
- Confirm the entry appears in event history.
- Confirm bonuses increase the balance and infractions decrease it.
- Employees in multiple programs must have one shared balance.

## Correct a Mistake
- Identify the incorrect entry in event history.
- Use the approved reversal workflow when available.
- Preserve the original record and document the correction.
- If reversal is unavailable, contact the designated administrator.
